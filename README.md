# Reproduction

This repository is for reproductions of experiments from papers I have read.

| Directory | Paper |
|---|---|
| [`deepproblog/`](deepproblog/) | Manhaeve et al., [*DeepProbLog: Neural Probabilistic Logic Programming*](https://arxiv.org/abs/1805.10872), NeurIPS 2018 |
| [`deepstochlog/`](deepstochlog/) | Winters et al., [*DeepStochLog: Neural Stochastic Logic Programming*](https://arxiv.org/abs/2106.12574), AAAI 2022 |
| [`problog/`](problog/) | De Raedt et al., [*ProbLog: A Probabilistic Prolog and Its Application in Link Discovery*](https://www.ijcai.org/Abstract/07/396), IJCAI 2007 |

Dependencies and running instructions are provided in each project.
